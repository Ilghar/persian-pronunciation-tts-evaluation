# Persian pronunciation and expressive TTS evaluation

> How can a small reproducible Persian evaluation expose pronunciation, ezafe, numeral, register and code-switching errors without confusing subjective prosody with intelligibility?

**Status:** Real MOSS-TTS-Nano CPU output measured at signal level only; no pronunciation ratings. Private work in progress.

## Limitations
- One upstream TTS run (MOSS-TTS-Nano-100M, CPU); audio not listened to, so pronunciation, intelligibility and naturalness are unmeasured.
- Seeded reruns are not bit-identical (0/12); ratings must be keyed to audio sha256.
- Mock tone audio (M03/M04) is not speech and is never a baseline.
- Reference pronunciations and spans are unreviewed.
- 12 items; deterministic split gives 11 dev / 1 test, too small for a test claim.
- Illustration (assets/ASSETS.json) is for illustration only and is stored on Drive, not git; the native diagram is authoritative.
